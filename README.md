Three Website Projects Using HTML and CSS

About the Project

This project contains three simple and responsive website designs created using HTML and CSS. These websites demonstrate basic web development concepts such as page structure, styling, navigation, cards, forms, and layouts.

Projects Included

1. Personal Portfolio Website

A personal portfolio website that introduces Prabhas Ramaphalam and displays basic personal, educational, and contact information.

Features:

Personal introduction

Educational details

Skills and interests

Contact information

Simple and clean design

2. Sweet Cake Shop Website

A bakery website designed to showcase cakes, puffs, and other bakery products.

Features:

Bakery introduction

Product cards with images and prices

Attractive colors and styling

Contact information

Easy-to-understand layout

3. College Fest 2026 Website

A college festival website designed to provide information about college events and registration.

Features:

College fest introduction

Event cards

Event schedule

Registration form

Fest-related information

Technologies Used

HTML5 – To create the structure of the webpages.

CSS3 – To style the webpages, including colors, layouts, spacing, and fonts.

How to Run the Projects

Download or clone the project files.

Save the HTML and CSS files in the appropriate folders.

Open the required HTML file in a web browser such as Google Chrome or Microsoft Edge.

Explore the website and its features.

No additional software or JavaScript is required to view these websites.
